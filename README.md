Employee Attrition Analysis and Prediction

Project Overview

This project analyzes employee attrition using HR analytics data. It identifies factors associated with employees leaving an organization and uses a machine learning model to predict employee attrition.

Objectives

- Analyze employee attrition patterns.
- Study attrition by department, age, monthly income, and overtime.
- Identify factors associated with employee resignation.
- Build a classification model to predict employee attrition.
- Present findings through charts and key performance indicators.

Dataset

- Dataset: IBM HR Analytics Employee Attrition
- Total Records: 1,470 employees
- Total Columns: 35
- Missing Values: 0

Tools and Technologies

- Python
- Jupyter Notebook
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn

Key Results

- Total employees: 1,470
- Employees who left: 237
- Employees who stayed: 1,233
- Overall attrition rate: 16.12%
- Logistic Regression test accuracy: 75.17%

Visualizations

- Employee attrition count
- Department-wise attrition
- Monthly income versus attrition
- Attrition by overtime
- Employee age distribution
- Model evaluation using a confusion matrix

Project Files

- "Employee_Attrition_Analysis.ipynb" — Analysis and machine learning notebook
- "Employee_Attrition_Analysis.html" — Exported notebook with outputs and visualizations
- "WA_Fn-UseC_-HR-Employee-Attrition.csv" — Dataset

Conclusion

This project provides insights into employee attrition patterns and demonstrates how Python and machine learning can support HR decision-making. The model achieved 75.17% test accuracy. Its performance should also be evaluated using precision, recall, and F1-score.
