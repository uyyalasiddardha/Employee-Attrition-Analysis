Employee Attrition Analysis and Prediction

Project Overview

This project analyzes employee attrition using HR analytics data. The objective is to identify factors associated with employees leaving an organization and build a machine learning model to predict employee attrition.

Objectives

- Analyze employee attrition patterns.
- Study attrition by department, age, monthly income, and overtime.
- Identify possible factors associated with employee resignation.
- Build a classification model to predict employee attrition.
- Present findings through charts and key performance indicators.

Tools and Technologies

- Python
- Jupyter Notebook
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Logistic Regression

Dataset

IBM HR Analytics Employee Attrition dataset containing 1,470 employee records and 35 columns.

Key Results

- Total employees: 1,470
- Employees who left: 237
- Employees who stayed: 1,233
- Overall attrition rate: 16.12%
- Logistic Regression test accuracy: 75.17%

Visualizations and Analysis

- Employee attrition count
- Department-wise attrition
- Monthly income versus attrition
- Attrition by overtime
- Employee age distribution
- Model evaluation using a confusion matrix

Project Files

- "Employee_Attrition_Analysis.ipynb" — Jupyter Notebook containing the analysis and model.
- "Employee_Attrition_Analysis.html" — Exported notebook with outputs and visualizations.
- "WA_Fn-UseC_-HR-Employee-Attrition.csv" — Dataset.

Conclusion

This project provides insights into employee attrition patterns and demonstrates how Python and machine learning can support HR decision-making. The model's accuracy is 75.17% on the test dataset; its performance should also be assessed using precision, recall, and F1-score.
